# Sandbox Environment, Step 2: funraise-sync and donation-rollups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `funraise-sync` and `donation-rollups` — both currently deployed against the CRM
Sandbox *under their production names* — gain a `sandbox` Wrangler environment with its own
name, D1, queues, secrets, and `config/sandbox.json`, so `config/svbc.json` returns to a
production-only file and the two production names are freed for the October cutover.

**Architecture:** Same shape as step 1 (`donor-portal`, MR [GL!74](https://gitlab.com/silicon-valley-bicycle-coalition/svbc-monday-workers/-/merge_requests/74)): `src/environment.ts`
(copied verbatim) selects `config/sandbox.json` or `config/svbc.json` at request time from the
`ENVIRONMENT` var, memoized per environment; `wrangler.jsonc` gains an `env.sandbox` block whose
queues carry a `-sandbox` suffix; `config/split.test.ts` asserts the two configs share no id and
that `env.sandbox` shares no resource with the top level. Neither Worker emits anything outside
Monday, so there is no sink to lock — the split is purely so sandbox and production can coexist.
`donation-rollups` additionally routes its dead-letter batches by `queueBaseName()`, and its
four operator scripts that read `config/svbc.json` gain a `--config` flag. The live move (new
D1s seeded from the old ones, webhooks re-registered at the `-sandbox` URLs, Funraise's webhook
repointed, the production-named Workers deleted) is an operator task at the end.

**Tech Stack:** Hono + TypeScript strict (`noUncheckedIndexedAccess`), Wrangler 4.x
(`wrangler.jsonc` with `env.*`), D1, Queues, Vitest with `@cloudflare/vitest-plugin` (tests run
inside workerd; file contents are read via Vite `?raw`). Commands run from each Worker's own
directory: `npm test`, `npm run typecheck`. Node ESM scripts under `donation-rollups/scripts/`.

**Spec:** [`docs/superpowers/specs/2026-09-18-sandbox-environment-design.md`](../specs/2026-09-18-sandbox-environment-design.md) — read "Design" §1, §2, §5 and "9. Moving the two already-deployed Workers" before starting. This plan is the spec's "Rollout order" step 2. The step 1 plan, [`2026-09-18-sandbox-environment-donor-portal.md`](2026-09-18-sandbox-environment-donor-portal.md), is the reference implementation this plan copies from.

`src/environment.ts` — identical to `donor-portal/src/environment.ts` on this branch:

```ts
// Which deployment this isolate is: production (the default — the top level of wrangler.jsonc)
// or sandbox (`wrangler deploy --env sandbox`, which sets the ENVIRONMENT var). The sandbox is a
// permanent parallel environment that runs against the CRM Sandbox boards and must never emit
// data to a donor or a vendor's production account — see
// ../docs/superpowers/specs/2026-09-18-sandbox-environment-design.md.
export type Environment = 'production' | 'sandbox';

// The one var this module reads. Declared as its own interface so the entrypoint's full Env can
// be passed in and tests can pass a bare object.
export interface EnvironmentBindings {
  ENVIRONMENT?: string;
}

export function environmentOf(env: EnvironmentBindings): Environment {
  const value = env.ENVIRONMENT;
  if (value === undefined || value === '' || value === 'production') return 'production';
  if (value === 'sandbox') return 'sandbox';
  // Fail closed: an unrecognized name could be a typo'd "sandbox" about to hit production ids.
  throw new Error(`ENVIRONMENT var must be "sandbox" or unset (production); got "${value}"`);
}

export interface ConfigSources<T> {
  production: unknown;
  sandbox: unknown;
  validate: (raw: unknown) => T;
}

// Returns a `configFor(env)` function. Config was previously a module-scope import of one JSON
// file; with two files the choice can only happen once `env` is in hand (a handler), so this
// memoizes per environment to keep validation at once-per-isolate rather than once-per-request.
// A throwing validation is not memoized: the next request throws again, matching the existing
// "fail loudly on placeholder config" behavior.
export function createConfigSelector<T>(sources: ConfigSources<T>): (env: EnvironmentBindings) => T {
  const memo = new Map<Environment, T>();
  return (env) => {
    const environment = environmentOf(env);
    if (memo.has(environment)) return memo.get(environment) as T;
    const config = sources.validate(environment === 'sandbox' ? sources.sandbox : sources.production);
    memo.set(environment, config);
    return config;
  };
}

const SANDBOX_QUEUE_SUFFIX = '-sandbox';

// Sandbox queues are the production names plus "-sandbox" (wrangler.jsonc env.sandbox.queues).
// The queue router compares against this so one router serves both environments. Strips exactly
// one trailing suffix and nothing else, so "…-sandbox-dlq" never matches a consumer branch.
export function queueBaseName(queueName: string): string {
  return queueName.endsWith(SANDBOX_QUEUE_SUFFIX) ? queueName.slice(0, -SANDBOX_QUEUE_SUFFIX.length) : queueName;
}
```

`test/jsonc.ts`:

```ts
// Minimal JSONC reader for tests: strips // and /* */ comments outside string literals and
// removes trailing commas, then hands the result to JSON.parse. Enough for wrangler.jsonc; not
// a general parser.
export function parseJsonc(text: string): unknown {
  let out = '';
  let i = 0;
  let inString = false;
  while (i < text.length) {
    const ch = text[i]!;
    const next = text[i + 1];
    if (inString) {
      out += ch;
      if (ch === '\\' && next !== undefined) {
        out += next;
        i += 2;
        continue;
      }
      if (ch === '"') inString = false;
      i += 1;
      continue;
    }
    if (ch === '"') {
      inString = true;
      out += ch;
      i += 1;
      continue;
    }
    if (ch === '/' && next === '/') {
      while (i < text.length && text[i] !== '\n') i += 1;
      continue;
    }
    if (ch === '/' && next === '*') {
      i += 2;
      while (i < text.length && !(text[i] === '*' && text[i + 1] === '/')) i += 1;
      i += 2;
      continue;
    }
    out += ch;
    i += 1;
  }
  return JSON.parse(out.replace(/,(\s*[}\]])/g, '$1'));
}

import { describe, it, expect } from 'vitest';
import production from './svbc.json';
import sandbox from './sandbox.json';
import wranglerText from '../wrangler.jsonc?raw';
import { parseJsonc } from '../test/jsonc';
import { validateConfig } from '../src/config';
import { queueBaseName } from '../src/environment';
import { isDeadLetterBatch } from '../src/index';

// Keeps the sandbox and production deployments apart at the repo level: sandbox.json is the
// real, complete CRM Sandbox config; svbc.json is production and may hold no sandbox id; and
// env.sandbox in wrangler.jsonc shares no resource with the top level. See the design doc
// docs/superpowers/specs/2026-09-18-sandbox-environment-design.md §5.

const PLACEHOLDER = 'REPLACE_WITH_COLUMN_ID';

type Json = Record<string, unknown>;
const get = (obj: unknown, path: string): unknown =>
  path.split('.').reduce<unknown>((o, key) => (o as Json | undefined)?.[key], obj);

const wrangler = parseJsonc(wranglerText) as Json;
const sandboxEnv = get(wrangler, 'env.sandbox') as Json;

function columnIds(columns: Record<string, unknown>): string[] {
  return Object.values(columns).flatMap((v) =>
    typeof v === 'string' ? [v] : v !== null && typeof v === 'object' ? columnIds(v as Record<string, unknown>) : []
  );
}

describe('config split: board ids', () => {
  it('the sandbox Donations board is the CRM Sandbox one and production is the placeholder', () => {
    expect(sandbox.donationRollups.donationBoards[0]!.boardId).toBe(18428131791);
    expect(production.donationRollups.donationBoards[0]!.boardId).toBe(0);
  });

  it('owner boards are the three CRM Sandbox boards in sandbox and a placeholder in production', () => {
    expect(Object.keys(sandbox.donationRollups.ownerColumnsByBoard).sort()).toEqual(['18428131727', '18428131737', '18428131744']);
    expect(Object.keys(production.donationRollups.ownerColumnsByBoard)).toEqual(['0']);
  });

  it('custodian ids are real in sandbox and null or placeholder in production', () => {
    expect(sandbox.custodian.workspaceId).toBe(17141226);
    expect(sandbox.custodian.annualSummaryBoardId).toBe(18429045784);
    expect(production.custodian.workspaceId).toBe(0);
    expect(production.custodian.alertItemId).toBeNull();
    expect(production.custodian.annualSummaryBoardId).toBeNull();
  });
});

describe('config split: column ids', () => {
  it('no sandbox column id appears anywhere in production', () => {
    const sandboxIds = new Set([
      ...columnIds(sandbox.donationRollups.donationBoards[0]!.columns as Record<string, unknown>),
      ...Object.values(sandbox.donationRollups.ownerColumnsByBoard).flatMap((c) => columnIds(c as Record<string, unknown>)),
      ...columnIds((sandbox.custodian.annualSummaryColumns ?? {}) as Record<string, unknown>),
    ]);
    expect(sandboxIds.size).toBeGreaterThan(40);
    expect(sandboxIds.has(PLACEHOLDER)).toBe(false);

    const productionText = JSON.stringify(production);
    for (const id of sandboxIds) {
      expect(productionText, id).not.toContain(`"${id}"`);
    }
  });

  it('both shipped configs validate', () => {
    expect(() => validateConfig(sandbox)).not.toThrow();
    expect(() => validateConfig(production)).not.toThrow();
  });
});

describe('wrangler.jsonc env.sandbox', () => {
  it('sets only the ENVIRONMENT var, and never at the top level', () => {
    expect(sandboxEnv.vars).toEqual({ ENVIRONMENT: 'sandbox' });
    expect((wrangler.vars as Json | undefined)?.ENVIRONMENT).toBeUndefined();
  });

  it('uses sandbox-suffixed queue names that map back to the production queues', () => {
    const prodProducers = ((wrangler.queues as Json).producers as { queue: string }[]).map((p) => p.queue);
    const sbQueues = sandboxEnv.queues as Json;
    for (const producer of sbQueues.producers as { queue: string }[]) {
      expect(producer.queue.endsWith('-sandbox')).toBe(true);
      expect(prodProducers).toContain(queueBaseName(producer.queue));
    }
  });

  it('routes the sandbox dead-letter queue to the dead-letter consumer and nothing else', () => {
    const consumers = (sandboxEnv.queues as Json).consumers as { queue: string; dead_letter_queue?: string }[];
    const recompute = consumers.find((c) => c.dead_letter_queue !== undefined)!;
    const dlq = consumers.find((c) => c.dead_letter_queue === undefined)!;
    expect(recompute.queue).toBe('donation-rollups-recompute-sandbox');
    expect(recompute.dead_letter_queue).toBe('donation-rollups-recompute-sandbox-dlq');
    expect(dlq.queue).toBe(recompute.dead_letter_queue);
    expect(isDeadLetterBatch(dlq.queue)).toBe(true);
    expect(isDeadLetterBatch(recompute.queue)).toBe(false);
  });

  it('mirrors the production consumer limits', () => {
    const prod = ((wrangler.queues as Json).consumers as Json[]).map((c) => [c.max_batch_size, c.max_retries, c.max_concurrency]);
    const sb = ((sandboxEnv.queues as Json).consumers as Json[]).map((c) => [c.max_batch_size, c.max_retries, c.max_concurrency]);
    expect(sb).toEqual(prod);
  });

  it('has its own D1 database, never production’s', () => {
    const prodDb = (wrangler.d1_databases as Json[])[0]!;
    const sbDb = (sandboxEnv.d1_databases as Json[])[0]!;
    expect(sbDb.database_name).toBe('svbc-donation-rollups-sandbox');
    expect(sbDb.database_name).not.toBe(prodDb.database_name);
    expect(sbDb.database_id).not.toBe(prodDb.database_id);
  });

  it('keeps the same cron schedule as production and derives its own name', () => {
    expect((sandboxEnv.triggers as Json).crons).toEqual((wrangler.triggers as Json).crons);
    expect(sandboxEnv.name).toBeUndefined();
    expect(wrangler.name).toBe('svbc-donation-rollups');
  });
});
```
