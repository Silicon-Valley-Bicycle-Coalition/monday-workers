# Sandbox Environment, Step 1: donor-portal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `donor-portal` gains a `sandbox` Wrangler environment that runs against the CRM Sandbox
boards and can only ever email `sandbox@bikesiliconvalley.org`, enforced by the send binding's
allowlist and, independently, by a binding wrapper — so staff can request a login link as any
real donor with zero chance that donor receives it.

**Architecture:** `wrangler.jsonc` gets an `env.sandbox` block (own name, D1, queues, rate-limit
namespace, cron, custom domain, `ENVIRONMENT` and `SANDBOX_EMAIL_SINK` vars, and an `EMAIL`
binding restricted to the sink). The entrypoint imports both `config/svbc.json` and a new
`config/sandbox.json` and picks one at request time from `env.ENVIRONMENT` via a memoized
selector in a new `src/environment.ts`, which also provides `queueBaseName()` so the queue
router serves both environments' queue names. In the sandbox, `env.EMAIL` is wrapped by
`sandboxEmailBinding()` (new `src/email/sandboxBinding.ts`), which rewrites every recipient to
the sink, prefixes the subject with the original recipient, prepends a notice, and logs a
`sandboxOutbound` line. A `config/split.test.ts` asserts the two configs disagree on every sink
and that the allowlist is present in `wrangler.jsonc`. This Worker is the reference
implementation: steps 2 and 3 of the spec copy `environment.ts`, the split test, and the
`env.sandbox` shape.

**Tech Stack:** Hono + TypeScript strict (`noUncheckedIndexedAccess`), Cloudflare Workers,
Wrangler 4.125 (`wrangler.jsonc` with `env.*`), Cloudflare Email Service `send_email` binding,
D1, Queues, Vitest 4 with `@cloudflare/vitest-plugin` (tests run inside workerd; `node:fs` is
not available, so file contents are imported via Vite `?raw`). Commands run from
`donor-portal/`: `npm test`, `npm run typecheck`. Monday.com GraphQL API (`API-Version:
2026-01`) for the one live column-creation task.

**Spec:** [`docs/superpowers/specs/2026-09-18-sandbox-environment-design.md`](../specs/2026-09-18-sandbox-environment-design.md) — read "Design" §1–§5 and "Testing" before starting. This plan covers the spec's "Rollout order" step 1 only.

Create `src/environment.ts`:

```ts
// Which deployment this isolate is: production (the default — the top level of wrangler.jsonc)
// or sandbox (`wrangler deploy --env sandbox`, which sets the ENVIRONMENT var). The sandbox is a
// permanent parallel environment that runs against the CRM Sandbox boards and must never emit
// data to a donor or a vendor's production account — see
// docs/superpowers/specs/2026-09-18-sandbox-environment-design.md.
export type Environment = 'production' | 'sandbox';

// The one var this module reads. Declared as its own interface so the entrypoint's full Env can
// be passed in and tests can pass a bare object.
export interface EnvironmentBindings {
  ENVIRONMENT?: string;
}

export function environmentOf(env: EnvironmentBindings): Environment {
  const value = env.ENVIRONMENT;
  if (value === undefined || value === '' || value === 'production') return 'production';
  if (value === 'sandbox') return 'sandbox';
  // Fail closed: an unrecognized name could be a typo'd "sandbox" about to hit production ids.
  throw new Error(`ENVIRONMENT var must be "sandbox" or unset (production); got "${value}"`);
}

export interface ConfigSources<T> {
  production: unknown;
  sandbox: unknown;
  validate: (raw: unknown) => T;
}

// Returns a `configFor(env)` function. Config was previously a module-scope import of one JSON
// file; with two files the choice can only happen once `env` is in hand (a handler), so this
// memoizes per environment to keep validation at once-per-isolate rather than once-per-request.
// A throwing validation is not memoized: the next request throws again, matching the existing
// "fail loudly on placeholder config" behavior.
export function createConfigSelector<T>(sources: ConfigSources<T>): (env: EnvironmentBindings) => T {
  const memo = new Map<Environment, T>();
  return (env) => {
    const environment = environmentOf(env);
    const cached = memo.get(environment);
    if (cached !== undefined) return cached;
    const config = sources.validate(environment === 'sandbox' ? sources.sandbox : sources.production);
    memo.set(environment, config);
    return config;
  };
}

const SANDBOX_QUEUE_SUFFIX = '-sandbox';

// Sandbox queues are the production names plus "-sandbox" (wrangler.jsonc env.sandbox.queues).
// The queue router compares against this so one router serves both environments. Strips exactly
// one trailing suffix and nothing else, so "…-sandbox-dlq" never matches a consumer branch.
export function queueBaseName(queueName: string): string {
  return queueName.endsWith(SANDBOX_QUEUE_SUFFIX) ? queueName.slice(0, -SANDBOX_QUEUE_SUFFIX.length) : queueName;
}
```

```ts
import { escapeHtml } from '../views';

// Wraps the EMAIL send binding in the sandbox environment so that no message can leave for a
// donor: every recipient is replaced with the sink address and the original recipient is
// preserved in the subject, a body notice, and a header for whoever reads the sandbox inbox.
//
// This is the *code* layer. The *platform* layer is wrangler.jsonc's
// env.sandbox.send_email[0].allowed_destination_addresses, which makes Cloudflare reject any
// other recipient with E_RECIPIENT_NOT_ALLOWED even if this wrapper were removed. Both must
// name the same address — config/split.test.ts checks that.
//
// Wraps the binding rather than EmailSender because the subject is composed inside
// CloudflareEmailSender; only the binding sees the final message.

export const SANDBOX_ORIGINAL_RECIPIENT_HEADER = 'X-SVBC-Sandbox-Original-To';

type Recipients = EmailMessageBuilder['to'];

function isBuilder(message: EmailMessage | EmailMessageBuilder): message is EmailMessageBuilder {
  return typeof (message as Partial<EmailMessageBuilder>).subject === 'string';
}

function addressesOf(value: Recipients | undefined): string[] {
  if (value === undefined) return [];
  const list = Array.isArray(value) ? value : [value];
  return list.map((entry) => (typeof entry === 'string' ? entry : entry.email));
}

export function sandboxEmailBinding(inner: SendEmail, sink: string): SendEmail {
  return {
    async send(message: EmailMessage | EmailMessageBuilder): Promise<EmailSendResult> {
      if (!isBuilder(message)) {
        // A raw MIME message can carry recipients in its own headers that this wrapper cannot
        // see, so it is refused outright. The portal only ever sends the builder form.
        throw new Error('sandbox email binding: raw EmailMessage sends are not supported; use the builder form');
      }

      const originalRecipients = [...addressesOf(message.to), ...addressesOf(message.cc), ...addressesOf(message.bcc)];
      const originalTo = originalRecipients.join(', ');
      const notice = `Sandbox copy. Production would have sent this to ${originalTo}.`;

      console.log(JSON.stringify({ sandboxOutbound: 'email', originalTo: originalRecipients, subject: message.subject }));

      // cc/bcc are dropped, not rewritten: one copy to the sink is the whole point.
      const { cc: _cc, bcc: _bcc, ...rest } = message;
      return inner.send({
        ...rest,
        to: sink,
        subject: `[sandbox → ${originalTo}] ${message.subject}`,
        text: message.text === undefined ? undefined : `${notice}\n\n${message.text}`,
        html: message.html === undefined ? undefined : `<p><strong>${escapeHtml(notice)}</strong></p>${message.html}`,
        headers: { ...(message.headers ?? {}), [SANDBOX_ORIGINAL_RECIPIENT_HEADER]: originalTo },
      });
    },
  };
}
```

```ts
// Minimal JSONC reader for tests: strips // and /* */ comments outside string literals and
// removes trailing commas, then hands the result to JSON.parse. Enough for wrangler.jsonc; not
// a general parser.
export function parseJsonc(text: string): unknown {
  let out = '';
  let i = 0;
  let inString = false;
  while (i < text.length) {
    const ch = text[i]!;
    const next = text[i + 1];
    if (inString) {
      out += ch;
      if (ch === '\\' && next !== undefined) {
        out += next;
        i += 2;
        continue;
      }
      if (ch === '"') inString = false;
      i += 1;
      continue;
    }
    if (ch === '"') {
      inString = true;
      out += ch;
      i += 1;
      continue;
    }
    if (ch === '/' && next === '/') {
      while (i < text.length && text[i] !== '\n') i += 1;
      continue;
    }
    if (ch === '/' && next === '*') {
      i += 2;
      while (i < text.length && !(text[i] === '*' && text[i + 1] === '/')) i += 1;
      i += 2;
      continue;
    }
    out += ch;
    i += 1;
  }
```

```ts
import { describe, it, expect } from 'vitest';
import production from './svbc.json';
import sandbox from './sandbox.json';

import { parseJsonc } from '../test/jsonc';

// disagree on every outbound sink, the sandbox must be a complete real config, and the
// platform-side email allowlist must still be in wrangler.jsonc. See the design doc
// docs/superpowers/specs/2026-09-18-sandbox-environment-design.md §5.

const SINK = 'sandbox@bikesiliconvalley.org';
const PLACEHOLDER = 'REPLACE_WITH_COLUMN_ID';

type Json = Record<string, unknown>;
const get = (obj: unknown, path: string): unknown =>
  path.split('.').reduce<unknown>((o, key) => (o as Json | undefined)?.[key], obj);

const wrangler = parseJsonc(wranglerText) as Json;
const sandboxEnv = get(wrangler, 'env.sandbox') as Json;

describe('config split: sinks', () => {
  it.each(['auth.portalBaseUrl', 'email.fromName'])('%s differs between production and sandbox', (path) => {
    const prod = get(production, path);
    const sb = get(sandbox, path);
    expect(typeof prod).toBe('string');
    expect(typeof sb).toBe('string');
    expect(sb).not.toBe(prod);
  });

  it('sandbox portalBaseUrl is the sandbox custom domain from wrangler.jsonc', () => {
    const routes = sandboxEnv.routes as { pattern: string }[];
    expect(get(sandbox, 'auth.portalBaseUrl')).toBe(`https://${routes[0]!.pattern}`);
  });
});

describe('config split: board and column ids', () => {
  it.each(['monday.donorsBoardId', 'monday.donationsBoardId', 'monday.organizationsBoardId', 'letterCron.boardId'])(
    '%s is a real sandbox id and production is null or different',
    (path) => {
      const sb = get(sandbox, path);
      const prod = get(production, path);
      expect(typeof sb).toBe('number');
      expect(sb).toBeGreaterThan(0);
      expect(prod === null || prod !== sb).toBe(true);
    }
  );

  it('no real sandbox column id appears in production', () => {
    const sbColumns = get(sandbox, 'monday.columns') as Record<string, string>;
    const prodColumns = get(production, 'monday.columns') as Record<string, string>;

      if (sbValue === PLACEHOLDER) continue;
      expect(prodColumns[key], `monday.columns.${key}`).not.toBe(sbValue);
    }
    const sbLetter = get(sandbox, 'letterCron.columns') as Record<string, unknown>;
    const prodLetter = get(production, 'letterCron.columns') as Record<string, unknown>;

    expect(letterCronConfigured(config)).toBe(true);

describe('wrangler.jsonc env.sandbox', () => {
  it('locks the EMAIL binding to exactly the sink address', () => {
    expect(sandboxEnv.send_email).toEqual([{ name: 'EMAIL', allowed_destination_addresses: [SINK] }]);
  });

  it('sets the vars the entrypoint reads, with the sink matching the allowlist', () => {
    expect(sandboxEnv.vars).toEqual({ ENVIRONMENT: 'sandbox', SANDBOX_EMAIL_SINK: SINK });
  });

  it('does not restrict production sends', () => {
    expect(wrangler.send_email).toEqual([{ name: 'EMAIL' }]);
  });

  it('uses sandbox-suffixed queue names that map back to the production queues', () => {
    const prodProducers = ((wrangler.queues as Json).producers as { queue: string }[]).map((p) => p.queue);
    const sbQueues = sandboxEnv.queues as Json;
    for (const producer of sbQueues.producers as { queue: string }[]) {
      expect(producer.queue.endsWith('-sandbox')).toBe(true);
      expect(prodProducers).toContain(queueBaseName(producer.queue));
    }
    for (const consumer of sbQueues.consumers as { queue: string; dead_letter_queue: string }[]) {
      expect(consumer.queue.endsWith('-sandbox')).toBe(true);
      expect(consumer.dead_letter_queue).toBe(`${consumer.queue}-dlq`);
    }
  });

  it('has its own D1 database, never production’s', () => {
    const prodDb = (wrangler.d1_databases as Json[])[0]!;
    const sbDb = (sandboxEnv.d1_databases as Json[])[0]!;

    expect(sbDb.database_name).not.toBe(prodDb.database_name);

    expect(bothPlaceholders || sbDb.database_id !== prodDb.database_id).toBe(true);
  });

  it('is not served on workers.dev or preview URLs (login portal)', () => {
    expect(sandboxEnv.workers_dev).toBe(false);
    expect(sandboxEnv.preview_urls).toBe(false);
  });
});
```
