# Logos

Both the black-and-gold and the grey-and-gold logo are allowed on light grounds; pick by context, one per piece.

- **svbc-logo-black.svg** — the official vector as SVBC's designer exported it: black box and bicycle, gold #FFC20E (`svbc-gold`; print CMYK 0/25/100/0). The default for slides, collateral, social, email signatures, forms and anything with `svbc-gold` in it.
- **svbc-logo.svg** — the letterhead colourway: grey box and bicycle (`svbc-grey` #727677), `svbc-gold-soft` #E8B85F "BICYCLE" and speech bubble, white lettering. The official vector recoloured to the 2026 letterhead. For the letterhead and documents built on it, beside `svbc-sand` and grey type.
- **svbc-logo.png** — the letterhead colourway, 1200px wide, transparent, for tools that won't take SVG (Word, Google Docs, slides).
- **svbc-wordmark.svg** — white lettering and gold bicycle bubble on transparent, cropped to its artwork (`viewBox="27 99 235 90"`). Dark grounds only (`svbc-chrome`, `svbc-black`, the member card); the website header and every Worker surface use it today. Size by CSS height with `width:auto`.
- **svbc-wordmark-email.png** — the dark-ground wordmark rasterized at 470×180 (2× the email header's 235px), transparent, for email.
- **svbc-icon.png** — 180×180 square bicycle icon, the portal favicon.

Don't redraw, outline or recolour the marks beyond these colourways; in particular, don't match the logo's gold to `svbc-gold-soft` or vice versa. Retire older rasters: grey-and-gold copies with a lemon gold (#FFD404) and logos under 300px wide. If the designer has a native file for the letterhead colourway, replace `svbc-logo.svg` with it.
