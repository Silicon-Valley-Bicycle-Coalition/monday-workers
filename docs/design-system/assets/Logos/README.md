# Logos

- **svbc-logo.svg** — the primary mark, in the 2026 letterhead's colourway: grey box and bicycle (`svbc-grey` #727677), gold "BICYCLE" and speech bubble (`svbc-gold` #E8B85F), white lettering. The official vector (Box: `SVBC-logo color.svg`) recoloured to the letterhead. For light grounds: letterhead, documents, white or sand pages.
- **svbc-logo.png** — the same, 1200px wide, transparent, for tools that won't take SVG (Word, Google Docs, slides).
- **svbc-logo-black.svg** — the official vector as SVBC's designer exported it: black box and bicycle, gold #FFC20E. The high-contrast version, for small sizes or one-colour contexts.
- **svbc-wordmark.svg** — white lettering and gold bicycle bubble on transparent, cropped to its artwork (`viewBox="27 99 235 90"`). Dark grounds only (`svbc-chrome`, `svbc-black`, the member card); the website header and every Worker surface use it today. Size by CSS height with `width:auto`.
- **svbc-wordmark-email.png** — the dark-ground wordmark rasterized at 470×180 (2× the email header's 235px), transparent, for email.
- **svbc-icon.png** — 180×180 square bicycle icon, the portal favicon.

Don't redraw, outline or recolour the marks beyond these colourways. If the designer has a native file for the letterhead colourway, replace `svbc-logo.svg` with it.
