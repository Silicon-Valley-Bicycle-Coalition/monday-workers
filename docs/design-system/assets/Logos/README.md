# Logos

- **svbc-wordmark.svg** — the SVBC wordmark (gold bicycle / speech-bubble mark, white lettering), cropped to its artwork (`viewBox="27 99 235 90"`). Only for dark grounds (`svbc-chrome`, `svbc-black`, the member card). Size by CSS height with `width:auto`.
- **svbc-wordmark-email.png** — the same artwork rasterized at 470×180 (2× the email header's 235px), transparent. For email, where inline SVG doesn't render. Regenerate from the SVG with resvg if the artwork changes.
- **svbc-icon.png** — 180×180 square bicycle icon, served as the portal favicon.

There is no light-ground version of the wordmark in the code. Don't recolour or outline it to make one.
