# RoadDivider
The website's signature decoration: a wavy, dashed black "road" across a full-bleed `svbc-gold` band, leading into a callout.

- Band: `svbc-gold` with `svbc-black` text and outline buttons (black border, 600 weight).
- Line: a gentle S-wave, stroke `svbc-black`, about 14px thick, dashes ~22px with ~14px gaps — read from the rendered site, not from its source (Squarespace generates it as a section divider).
- Use once per page at most, between a photo or dark section and a gold callout. Decorative only: `aria-hidden="true"`.
- Not used in Workers today; available for portal landing and email-free surfaces.
